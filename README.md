## Projects

### 1. HTTPS Security Checker

`checker.py` is a Python-based tool that performs basic HTTPS security checks.

It can:

- Check whether a website uses HTTPS
- Check HTTP response status
- Inspect selected security headers
- Generate a basic security report

Example:

```text

Status: 200
HSTS: PASS
CSP: PASS
